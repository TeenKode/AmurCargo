# Шилд RB / Keyes L298P и SG90 в AmurCargo

Экспериментальная версия для Arduino UNO R3 / Nano (ATmega328P/16 МГц) и **именно** RB/FunduMoto L298P Motor Shield, у которого PWM A=D10, DIR A=D12, PWM B=D11, DIR B=D13. Есть несовместимые платы L298P, где мотор A подключён к D3; перед установкой проверьте маркировку или схему вашей платы.

| Узел | Arduino | Пояснение |
|---|---|---|
| Мотор TT слева (Motor A) | D10 PWM, D12 DIR | Клемма Motor A |
| Мотор TT справа (Motor B) | D11 PWM, D13 DIR | Клемма Motor B |
| SG90 | D9 | SERVO, контакты G/+/S по маркировке |
| HW-511 | D2 | G→GND, V+→5V, S→D2 |
| Кнопка START | A3 / D17 | INPUT_PULLUP, на GND |
| Фоторезисторы | A0, A1, A2 | Существующие делители напряжения |
| Светодиод состояния | отключён (255) | D13 занят Motor B |
| Зуммер | D4 | При запуске удерживается в LOW |

**Конфликт таймеров:** стандартная `Servo.h` задействует Timer1 на UNO/Nano и отключает аппаратный PWM D10. Файл `firmware/RadialRobot/AmurServo.h` вместо неё выдаёт импульсы SG90 через прерывания сравнения Timer0 A/B на D9. Режим и предделитель Timer0, а также обработчик Timer0 overflow ядра Arduino не изменяются: `millis()`/`micros()` и аппаратный PWM D10/Timer1, D11/Timer2 сохраняются. **Не используйте PWM на D5/D6**: оба канала сравнения Timer0 заняты. Запрошенный диапазон импульсов 544–2400 мкс, период ≈20,48 мс. Проверьте возможный джиттер сервопривода на реальной плате.

Профиль фиксирует `DRIVER_MODE=2`, D10/D11/D12/D13, D9, а неиспользуемые IN2 равны 255. При несовместимых настройках Arduino выдаст `CONFIG ERROR 305`. Полярность HW-511 задаётся `CONTACT_LOW` (проверьте `contact` в USB `status`). Если моторы вращаются не в нужную сторону, используйте `LEFT_REVERSE` и `RIGHT_REVERSE`.

**Безопасная первая проверка:** сначала загрузите прошивку без подключённых моторов, проверьте `status`, HW-511 и SG90 без качалки. Затем с вывешенными колёсами выполните `arm`, `jog 80 0 200`, `jog 0 80 200` и `stop`. Используйте питание для моторов с достаточным пусковым током и отдельные стабильные 5 В для SG90, если серворазъём конкретного шилда не гарантирует достаточный ток. Проверьте перемычку объединения VIN/VMS перед подключением USB и внешнего питания; не соединяйте несовместимые источники. Общая земля обязательна. Прямоугольная «Крона» 9 В для моторов не подходит.

Этот профиль зависит от ветки `improve-line-following-recovery-speed-filter` (PR #2), поэтому отдельное слияние прямо в `main` преждевременно. Физические испытания ещё не проводились.
